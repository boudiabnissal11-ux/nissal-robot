## 🎯 شو هو Ghost؟

Ghost هو مساعد شخصي ذكي مبني بالبايثون، مصمم خصيصاً لنيسال.
بيشتغل على تيليجرام، واتساب، والمكالمات الهاتفية.

### الميزات:
- 🧠 **عقل ذكي** — بيفهم وبيحكي بالعربي
- 📝 **إدارة المهام** — بيضيف وبيراجع وبيمسح المهام
- 📅 **المواعيد** — بيذكّرك بالمواعيد المهمة
- 💳 **الاشتراكات** — بيتابع الاشتراكات وبيذكّرك بالتجديد
- 💰 **الدفع** — بيربط مع سترايب للدفع الإلكتروني
- 📱 **تيليجرام** — بيرد على الرسائل تلقائياً
- 💬 **واتساب** — بيرد على رسائل واتساب عبر تويليو
- 📞 **الهاتف** — مكالمات وSMS عبر تويليو
- 🗣️ **الصوت** — بيتكلم بصوت مخصص عبر ElevenLabs
- 🧠 **الذاكرة** — بيفتكر كل شي عنك

## ⚙️ التثبيت

1. نسخ المستودع:
git clone https://github.com/boudiabnissal11-ux/ghost-brain.git
cd ghost-brain

2. إنشاء بيئة افتراضية:
python -m venv venv
source venv/bin/activate

3. تثبيت المكتبات:
pip install -r requirements.txt

4. إعداد المتغيرات البيئية:
cp env.example .env
ثم عدّل ملف .env وأضف مفاتيح API

5. تشغيل الروبوت:
python main.py
